## Phase 4：Hybrid 模式实现（HE↔share 转换 + MPC ReLU）

按 `协议设计.md` §4 五步消息流实现，模块清单：

| 模块 | 规格 | 验收（单元测试） |
|---|---|---|
| 掩码采样 | `r = PRG(seed_session, q‖k)`，域对齐 M2（按训练集 z_k 分布域） | 断言 10⁴ 次采样无重复（M1） |
| HE-to-share | S 算 ct_{z+r}；C 解密即份额 s_c | 数值断言 s_c + (−r) ≡ z（定点容差内） |
| MPC ReLU | 加性共享 + silent OT/VOLE（SCI/CrypTFlow2），r_h=1 轮 | [ReLU(z)] 重构值 vs 明文 ReLU 相对误差 < 1e-3 |
| share-to-HE | C 再加密 Enc_pk(c_c)，S 加明文份额恢复 | 恢复密文解密值 vs σ(z) 误差 < 1e-3 |
| scale 对齐 | fresh 密文 scale=2^21 与岔路后 mm 的明文编码对齐 | 混合调度 s=01/10/11 全测试集精度 vs 明文下降 < 1% |
| 随机截断 | Beaver 后除 2^f 用随机截断（CryptGPU/ABY3 框架） | 对照直接截断的精度差（E7 消融用） |

实测回填：单 hybrid 层时延分解（dec/OT/enc）、每层 ①/② 消息实测字节、OT 字节（验 O(n_k·b)）。

## Phase 7：E10 泄漏量化（安全实验）

| 子实验 | 实现 | 度量 | 预期 |
